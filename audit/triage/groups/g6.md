2. `$` in code treated as TeX math delimiter, leaving stray `<i>` pairs: search `<i>` inside `<pre>` blocks containing `-reader|` or an odd number of `$`.
3. Hyphenated parameter names rendered with a space (`new-value` -> `new value`): grep `<i>[a-z]+ [a-z]+</i>` in Method Signatures/Syntax.
4. Lists generated by TeX macros (`\Meth`) copied with wrong repeated items: check other macro-generated lists.
5. Runs of `-` in code comments turned into `- -`: grep `- - ` in `<pre>`.
6. A literal `/` after `#\` dropped (`#\/` -> `#\ `): grep `#\\ ` followed by space or `)` in `<pre>`.
