## Systematic patterns (searchable book-wide)
1. **`\EQ` (≡) is rendered `==` with the following space lost**: `==(complex ...)` (164 occurrences of `==(`). The `==` itself is the EPUB's convention (1.4 defines it), so only the spacing is off.
2. **π rendered as the italic word `pi` with stray spaces** (`<i> pi </i>`, `<i>- pi /2</i>`) in 12.1, 12.2.21, 12.2.22, 12.2.23, 12.2.35, 12.2.49, 2.3. ε is a real Greek letter, so this is inconsistent; sqrt and log are likewise written as words. Not recorded as errors, since it is consistent ASCII math; the user decides.
3. **Runs of hyphens in code/format strings garbled to `- - -`**: 12.2.60 (fixed above); the same shape appears in 22.1 (line 580/596), 23.1 (64/79), 24.2.3 (`;- - [Begin file SETUP]- -`). Search `- - ` in `<pre>`.
4. **Unexpanded TeX macro names in code** (`\alfa` -> `\\alfa`): grep for `\\\\[a-z]+` in `<pre>`.
5. **Math/italic spill across paragraphs** (`</code><i>` ... `</i></p><p><i>`) after `{\tt ... $x$ ...}` in 12.2.77; search for `<i>\n\n</i></p><p><i>`.
6. Misplaced brackets around `\brac`/`\ttbrac` optional syntax (12.2.3/4/6/8); search `upper-limit)` book-wide (only these four).
